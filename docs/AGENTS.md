# Documentation scope

- Root `AGENTS.md` contains shared rules; do not repeat them here.
- Keep `context-map.md` an index of real entry points, not a repository dump.
- `architecture.md` explains boundaries and guarantees; `development.md` gives executable local workflows.
- Record decisions in root `DECISIONS.md`, acceptance work in `PLANS.md`, observed verification in `STATUS.md`.
- Separate implemented behavior from planned design. Never turn a roadmap requirement into a delivery claim.
- Keep code examples consistent with the Makefile, OpenAPI contract and actual environment names.
- Link authoritative sources for external technical claims; do not copy source text or attach private product documents to the repository.
